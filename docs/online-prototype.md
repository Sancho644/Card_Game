# Сетевая игра с другом

Первый прототип: частная комната на двух участников, вход по коду, собственные выбранные колоды. Правила партии совпадают с локальным режимом.

## Как играть

1. Оба игрока распаковывают одинаковый архив целиком и запускают CardGame.exe.
2. В коллекции выбирают корректную колоду, затем в меню нажимают «Играть с другом».
3. Один создаёт комнату и передаёт другу код. Второй вводит код и подключается.
4. Оба нажимают «Готов». Создатель остаётся ведущим до окончания сессии.

Нужен интернет. При выходе или потере соединения сессия закрывается без присуждения победы за отключение. Для следующей партии создайте новую комнату. Возврат в незавершённую партию, перенос роли ведущего, рейтинги и игровые таймеры не реализованы. Отдельная регистрация игрока не нужна: используется анонимный вход Unity.

## Реализация

- Multiplayer Services 2.4.1, Netcode for GameObjects 2.14.0, Newtonsoft JSON 3.2.2. Внешний выделенный игровой сервер не используется.
- Только ведущий исполняет LocalMatchSession. Подключение определяет игрока; клиент передаёт индекс допустимого действия, номер запроса и версию состояния. Повторные или устаревшие команды не исполняются повторно.
- OnlineMatchSession реализует асинхронную отправку с подтверждением. Представление, разрешённые действия и события передаются отдельно для получателя. Отладочное раскрытие второй руки в онлайне отключено.
- OnlineCodec использует закрытый список типов команд и событий, без разрешения CLR-типов из сообщений. Контракт полей восстанавливает неизменяемые представления Core; link.xml сохраняет эти типы при сборке.
- Отпечаток включает версию протокола, версию приложения, определения карт и правила. При изменениях сетевого контракта увеличивайте OnlineCodec.Protocol; при изменениях логики обновляйте версию приложения. Игрокам передавайте один и тот же архив.
- В OnlineSettings задаются ожидание подключения и ожидание подтверждения команды; это не игровые таймеры. Пока соединение активно, игра работает в фоне.
- В редакторе включена перезагрузка домена при входе в Play mode: это предотвращает накопление статических регистраций установленного сетевого SDK между запусками.
- Облачный проект уже привязан. Использование инфраструктуры Unity учитывается в его квотах.

Ведущий имеет полное состояние партии. Эта модель рассчитана на доверенную игру с другом, не на соревновательный режим с защитой от владельца сервера.

## Проверка 17 ноября 2026

88 тестов Presentation, включая полный матч через сериализацию представлений и событий, скрытую информацию, повторные/устаревшие команды и ожидание подтверждения.

Выполнен полный матч через интернет-подключение между обычным процессом ПК-билда (ведущий) и редактором (клиент). Оба получили итог 1:3; тестовые контроллеры выполнили 15 и 13 действий соответственно. Выход клиента закрыл сессию на другой стороне. Временные автоматические контроллеры удалены из итогового кода.

Оба экземпляра проверялись на одном компьютере через облачное соединение. Проверка на двух физических компьютерах в разных домашних сетях остаётся ручным приёмочным проходом с другом.

Билд, запускаемый из ограниченного терминала Codex, не мог сохранять Windows PlayerPrefs. Обычный запуск через Unity Build & Run прошёл этот этап; проверки сертификатов и безопасности не отключались.
