# Арты способностей

Для 33 способностей добавлены отдельные иллюстрации; существующий арт «Перехвата» сохранён. Все 34 основные карты способностей теперь имеют арт. Изображения лежат в `Assets/Art/Cards/Abilities/*-art-v1.png` и назначены через `_art` соответствующего AbilityDef.

Стиль: живописное фэнтези, выразительные силуэты магических эффектов, нефритовые тени, золото и индивидуальные цвета стихий. Без текста и внешних рамок; название, сила, редкость и правила остаются интерфейсом карты.

Импорт: Sprite Single, непрозрачные изображения, sRGB, Clamp, Bilinear, максимальная сторона 1024, стандартное сжатие, без mipmaps. Используется существующий общий AbilityCardFaceView, поэтому арт доступен в коллекции, на столе и в крупном просмотре.

Проверка: в Play mode построены все 34 шаблона карты через CardFaceBuilder и AbilityCardFaceView. У всех есть уникальный арт, нет ArtPlaceholder; RawImage получает правильную текстуру. Просмотрен общий лист изображений. Код правил, баланс и экспериментальные наборы Balance1/Balance2 не менялись.

Генерация: встроенный imagegen; отдельный запрос для каждой иллюстрации. Формат исходников — 4:3, с запасом по краям под центральное кадрирование. Описание запросов сохранено в ability-art-prompts.json.
