# Выбор поля ИИ — 12 ноября 2026

Исправлена причина, обнаруженная в [первом замере баланса](balance-2026-11-12.md): до выставления существ общий оценщик давал любому новому полю одинаковую стоимость. При равенстве выбирался первый пункт списка.

## Как выбирается поле

- Для начальной выкладки и пополнения пустого стола используется `FieldDeploymentScorer`.
- ИИ строит независимые прогнозы из своего `PlayerView` и обычных предположений `OpponentModel`. Реальное состояние скрытой руки и закрытых полей соперника не читается.
- На каждом поле рассматриваются возможные пары существ: свои оставшиеся в руке и предполагаемые у соперника. ИИ оценивает, какое своё существо выгоднее выставить против разных возможных противников.
- До монеты рассматриваются оба порядка начала хода. При замене поля используется уже известный активный игрок.
- Выставление существ и открытие выполняются командами обычного движка в копии партии. Закрытый и открытый варианты оцениваются отдельно, затем выбирается лучший для хозяина. Это учитывает модификаторы поля, сравнение силы, разрешённые способности и последствия по действующим условиям.
- Используется существующая приближённая оценка битвы и резерва способностей с весами из `AiConfig`. Это прогноз ближайшей битвы, а не полный поиск всех будущих партий.
- При действительно одинаковых оценках полей обычный ИИ выбирает по стабильному ID карты. Положение пункта в списке больше не служит критерием. У лёгкого ИИ сохраняются один вариант скрытой руки и шум решений; при выключенном шуме порядок также стабилен.

Правила, значения карт и настройки сложности не изменены. Другие решения ИИ сохраняют прежний алгоритм.

## Проверки

Через Unity MCP пройдены все 322 EditMode-теста. Новые сценарии проверяют:

- выбор подходящего поля для огненных и водных существ, обе стороны стола и все шесть перестановок списка;
- учёт «Закона слабейшего», даже когда у поля нет бонуса к стихии;
- одинаковые поля со стабильным разрешением равенства;
- отсутствие зависимости от настоящих скрытых карт противника и отсутствие изменений реальной партии при прогнозе;
- замену полей с учётом оставшихся существ;
- лёгкий профиль с выключенным шумом.

## Контроль на случайных колодах

Выполнены 1 000 партий normal/normal на случайных колодах с seed 1: все завершились, ошибок и зависаний нет, одна ничья. Для сравнения взяты первые 1 000 партий прежнего прогона. Проверено точное совпадение seed и обеих колод каждой пары; менялся только алгоритм ИИ.

## Проверка в Play mode

Начать несколько партий против ИИ и проверить начальную выкладку и пополнение пустого стола. Открываемые ботом поля должны подбираться под доступных ему существ и условия битвы. Легендарное поле не обязано выбираться всегда; при выгодном закрытом варианте бот может оставить поле закрытым.

Старый отчёт 13 000 партий остаётся историческим замером до этого исправления. После контрольной проверки выполнен [повторный полный замер: 11 000 партий с исправленным ИИ](balance-after-ai-2026-11-12.md). Следующий этап перед изменением баланса — точечные эксперименты с кандидатами.
