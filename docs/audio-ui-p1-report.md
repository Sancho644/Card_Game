## Архитектура и поведение

`UiButtons.Bind` и `UiButtons.Assign` принимают необязательный сигнал с прежним `Button` по умолчанию. Пустой сигнал оставляет кнопку под управлением обработчика результата. Привязка заменяет предыдущий обработчик. Проверяются активность кнопки, её доступность и доступность родительского интерфейса. Динамические фабрики коллекции используют тот же механизм. Поворот увеличенной карты, перерисовка списка и автоматическое сохранение имени при потере фокуса проходят без звуков.

`ActionBarView` и боевые списки выбора отправляют команды без предварительного click. `MatchPresenter` воспроизводит `UiConfirm` после принятой готовности, если битва ждёт ответа соперника. При завершении битвы, открытии поля, смене хода или принятом розыгрыше остаются соответствующие звуки Gameplay. Отклонённая команда показывает общий баннер и вызывает `UiDenied`. На источнике UI отказ ограничен интервалом 0,20 с по немасштабированному времени. Осмотр неизвестной карты проходит без звука выбора.

Новые `SoundCue` добавлены в конец под номерами 35–42. Все восемь клипов и `Button` используют один существующий источник группы `Master/UI`. `UiAudioScope` переиспользуется для каждого корневого Canvas. Маршруты SFX и Music сохраняются. При Mute и нулевом эффективном UI-уровне проигрыватель пропускает новый UI-вызов. Кнопка «Прослушать» отключается при Mute, нулевом Master или UI. Ползунки обновляют значения без запуска эффектов.

## Источники, импорт и уровни

Все эффекты синтезированы для Card_Game из фильтрованного шума, коротких резонансов и тональных переходов. Сторонних записей, семплов и лицензий на аудиоматериал нет. Клипы предназначены для использования и распространения в Card_Game, включая коммерческие сборки.

- Мастера в `AudioSources/UiP1/Masters/` записаны в mono WAV PCM24, 48 кГц. Игровые WAV в `Assets/Audio/SFX/UI/P1/` используют PCM16, mono, 44,1 кГц.
- На Standalone и Android применены PCM, Decompress On Load, Preload Audio Data, исходная частота. Нормализация отключена.
- Пики до коэффициентов близки к −16 dBFS для подтверждения и −18 dBFS для остальных сигналов. После коэффициентов из `SoundSettings` это около −17,1 dBFS для подтверждения и −19,1…−20,2 dBFS для остальных. Пик существующего `Button` — −19,0 dBFS. Начало и конец каждого экспортированного клипа переходят к нулю.
- [Скрипт рендера](../AudioSources/UiP1/render_ui_p1.py) использует синтезатор из Gameplay P1. [Манифест](../AudioSources/UiP1/render-manifest.json) хранит пики, коэффициенты, таймкоды и SHA-256. Экспорт проверен с Python 3.14, NumPy 2.5.5 и SoundFile 0.14.0.

```powershell
python AudioSources/UiP1/render_ui_p1.py --preview-dir Logs/AudioUiP1
```
